1

Crear las GPO base

Una GPO solo de usuario y otra solo de equipo: cada una procesa únicamente lo que le corresponde.

Import-Module GroupPolicy, ActiveDirectory
$dn   = (Get-ADDomain).DistinguishedName
$gpoU = "Medicalia-Empleados-Usuario"
$gpoE = "Medicalia-Empleados-Equipo"
New-GPO -Name $gpoU -Comment "Restricciones de usuario para empleados" | Out-Null
New-GPLink -Name $gpoU -Target "OU=Medicalia,$dn" -LinkEnabled Yes | Out-Null
(Get-GPO -Name $gpoU).GpoStatus = "ComputerSettingsDisabled"
New-GPO -Name $gpoE -Comment "Restricciones de equipo para empleados" | Out-Null
New-GPLink -Name $gpoE -Target "OU=Equipos,$dn" -LinkEnabled Yes | Out-Null
(Get-GPO -Name $gpoE).GpoStatus = "UserSettingsDisabled"
# Función auxiliar: escribe un valor de registro en la GPO de usuario
function Pol { param($Key,$Name,$Type,$Value)
    Set-GPRegistryValue -Name $gpoU -Key $Key -ValueName $Name -Type $Type -Value $Value | Out-Null }
2

Página de inicio, registro, Panel de control y PowerShell

$edge = "HKCU\Software\Policies\Microsoft\Edge"
Pol $edge "HomepageLocation" String "http://www.Medicalia.org/"
Pol $edge "HomepageIsNewTabPage" DWord 0
Pol $edge "ShowHomeButton" DWord 1
Pol $edge "RestoreOnStartup" DWord 4          # 4 = abrir una lista de páginas
Pol "$edge\RestoreOnStartupURLs" "1" String "http://www.Medicalia.org/"

$sys = "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System"
$exp = "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Explorer"
Pol $sys "DisableRegistryTools" DWord 2       # 2 = bloquea también regedit /s
Pol $exp "NoControlPanel" DWord 1             # también la app Configuración
Pol $exp "DisallowRun" DWord 1
Pol "$exp\DisallowRun" "1" String "powershell.exe"
Pol "$exp\DisallowRun" "2" String "powershell_ise.exe"
Pol "$exp\DisallowRun" "3" String "pwsh.exe"

DisallowRun solo frena lo que se lanza desde el Explorador. La regla de System32 del paso siguiente cierra el hueco, porque powershell.exe está dentro de System32.

3

Impedir ejecutar .exe de C:\Windows\System32

Usamos las directivas de restricción de software: una regla de ruta concreta gana al nivel predeterminado. Dejamos el nivel predeterminado sin restricción, bloqueamos System32 y añadimos excepciones para los procesos que el propio escritorio necesita.

$safer = "HKCU\Software\Policies\Microsoft\Windows\Safer\CodeIdentifiers"
Pol $safer "DefaultLevel" DWord 262144       # sin restricción por defecto
Pol $safer "PolicyScope" DWord 0
Pol $safer "TransparentEnabled" DWord 1      # vigila .exe, no DLL
function Regla-Ruta { param($Nivel,$Ruta)     # 0 = no permitido · 262144 = sin restricción
    $k = "$safer\$Nivel\Paths\{$([guid]::NewGuid())}"
    Pol $k "ItemData" ExpandString $Ruta
    Pol $k "SaferFlags" DWord 0 }
Regla-Ruta 0 "%SystemRoot%\System32"
foreach ($exe in "userinit","conhost","ctfmon","sihost","taskhostw","RuntimeBroker","dllhost",
                 "dwm","fontdrvhost","ApplicationFrameHost","WerFault","gpscript","cmd","icacls",
                 "backgroundTaskHost","smartscreen") {
    Regla-Ruta 262144 "%SystemRoot%\System32\$exe.exe"
}

cmd e icacls están en la lista porque los usa el script de «Mis Documentos» del paso 4.

4

Impedir guardar en «Mis Documentos»

Un script de inicio de sesión, guardado en SYSVOL dentro de la propia GPO, deniega al usuario la escritura en su carpeta Documentos:

$id   = (Get-GPO -Name $gpoU).Id
$dest = "\\$env:USERDNSDOMAIN\SYSVOL\$env:USERDNSDOMAIN\Policies\{$id}\User\Scripts\Logon"
New-Item -Path $dest -ItemType Directory -Force | Out-Null
@('@echo off',
  'icacls "%USERPROFILE%\Documents" /deny "%USERDOMAIN%\%USERNAME%:(OI)(CI)(WD,AD)"') |
  Set-Content -Path "$dest\bloquear_docs.cmd" -Encoding ASCII

Para que la GPO lo ejecute, se registra en la consola: gpmc.msc → Medicalia → Medicalia-Empleados-Usuario → Editar → Configuración de usuario → Directivas → Configuración de Windows → Scripts → Iniciar sesión → Agregar → bloquear_docs.cmd.

5

Impedir cambiar la hora (directiva de equipo)

Los derechos de usuario son una configuración de equipo y no tienen cmdlet, así que se hace en la consola: gpmc.msc → Equipos → Medicalia-Empleados-Equipo → Editar → Configuración del equipo → Directivas → Configuración de Windows → Configuración de seguridad → Directivas locales → Asignación de derechos de usuario → Cambiar la hora del sistema → solo Administradores y SERVICIO LOCAL.

SERVICIO LOCAL se mantiene para que el servicio de hora de Windows siga sincronizando el reloj.

6

Contraseñas y bloqueo de cuenta (PSO)

Una directiva de contraseñas en GPO solo se aplica a todo el dominio y afectaría también a los administradores. Por eso usamos un objeto de configuración de contraseñas (PSO), que se asigna a grupos:

$pso = @{
    Name = "PSO_Empleados"; Precedence = 10
    MaxPasswordAge = "120.00:00:00"     # cambio cada 120 días
    MinPasswordAge = "0.00:00:00"
    PasswordHistoryCount = 12           # no repetir las 12 anteriores
    MinPasswordLength = 8; ComplexityEnabled = $true; ReversibleEncryptionEnabled = $false
    LockoutThreshold = 3                # 3 intentos fallidos
    LockoutDuration = "00:05:00"        # bloqueo de 5 minutos
    LockoutObservationWindow = "00:05:00"
}
New-ADFineGrainedPasswordPolicy @pso
Add-ADFineGrainedPasswordPolicySubject -Identity "PSO_Empleados" `
    -Subjects 'G_Almacen','G_RRHH','G_Nutricion','G_Financiero','G_Operaciones','G_Presidencia'
Get-ADUserResultantPasswordPolicy -Identity pgamez                 # PSO_Empleados
Get-ADUserResultantPasswordPolicy -Identity Admin_GenteOperativa   # sin PSO
7

Directiva adicional: almacenamiento USB

Además de lo que pide el cliente, bloqueamos el acceso a memorias USB y discos externos en los equipos de los empleados, para evitar la fuga de datos de pacientes y la entrada de software no autorizado:

Set-GPRegistryValue -Name $gpoE -Key "HKLM\Software\Policies\Microsoft\Windows\RemovableStorageDevices" `
    -ValueName "Deny_All" -Type DWord -Value 1

Equivale a «Todas las clases de almacenamiento extraíble: denegar acceso a todo», en Plantillas administrativas → Sistema → Acceso de almacenamiento extraíble.

Decisiones

GPO de usuario y de equipo separadas

La página de inicio sigue al usuario; la hora y los USB dependen del equipo, lo use quien lo use.

PSO

Permite exigir 120 días, historial de 12 y bloqueo solo a los empleados.

Restricción de software

Bloquea System32 entero y deja pasar solo lo que el escritorio necesita.
